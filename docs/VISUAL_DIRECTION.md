# Visual direction

## Thesis

Delivery Composer should feel like a restrained consulting operations tool: matte graphite surfaces, editorial typography, thin trajectory lines, disciplined spacing, and one cool accent for action and state.

## Product intent

- Prioritize the working surface over marketing decoration.
- Make requirements, evidence, exceptions, and decisions easy to scan.
- Use full-width editorial rows instead of generic dashboard-card mosaics.
- Keep the generated trajectory field text-free and original.
- Preserve keyboard access, responsive layout, and reduced-motion behavior.

## Acceptance criteria

- [x] Product name is the strongest identity in the first viewport.
- [x] The interface contains no third-party logo or endorsement claim.
- [x] Every prominent control performs a visible action.
- [x] Evidence expansion and candidate comparison expose decision inputs.
- [x] Desktop and mobile layouts avoid unintended horizontal overflow.
- [x] Motion becomes still under reduced-motion preferences.
- [x] Synthetic-data and temporary-persistence boundaries are visible.
